Charger un fichier DAT/XML

Sélectionnez un DAT local ou téléchargez-en un, puis chargez-le dans RUMCET.

➕ Mode complémentaire — un DAT est déjà chargé (). Le DAT sélectionné sera fusionné dans la base actuelle : les jeux existants sont préservés, seuls les nouveaux jeux et les fichiers manquants seront ajoutés (ex : DAT CHDs qui complète un DAT ROMs, pack BIOS…).
1 Fichier DAT/XML Depuis votre disque ou depuis les sites des groupes de préservation
Sélectionnez un fichier .dat ou .xml présent sur votre disque.

2 Rumcet DB Créée automatiquement — personnalisable si besoin

RUMCET crée une base pour stocker les informations du DAT, des ROMs scannées et du matching. Par défaut, elle est nommée d'après le DAT et placée dans votre dossier Rumcet DB (modifiable dans les paramètres). Vous pouvez aussi choisir un autre emplacement ci-dessous.

3 📁 Dossier cible

Les ROMs conservées par la consolidation sont placées dans ce dossier.
