Options de compression

Détermine le niveau de compression pour les archives ZIP/7Z

Si désactivé, les archives dont le format et le contenu sont déjà conformes seront copiées directement sans recompression

⚠️ ATTENTION : Cette option ralentit FORTEMENT le processus !

L'application va créer une archive dans CHAQUE format compatible pour chaque jeu et ne conserver que celle dont la taille est la plus petite.

  • Temps de traitement : x3 à x5 plus lent
  • Utilisation CPU : Maximale
  • Utilisation disque : Temporairement doublée

Recommandé uniquement si l'espace disque final est critique.

Pour chaque jeu, toutes les variantes d'archives compatibles sont créées, puis seule la plus compacte est gardée (très lent)

La compression solide améliore le taux de compression mais ralentit l'extraction

Utilise plusieurs cœurs du processeur pour accélérer la compression

Arcade (MAME)

Mode du set cible

Spécifique aux DAT MAME (avec relations parent / clone / BIOS). Détermine comment RUMCET organisera vos ROMs sur disque après consolidation. Ce paramètre est ignoré pour les DAT non arcade (No-Intro / Redump). Voir docs/arcade-set-modes.md pour le détail des modes et leurs différences.

Le parent et le BIOS restent des archives séparées. Compact, mais chaque clone dépend du parent + BIOS pour fonctionner. Mode recommandé.

L'archive du clone contient ses ROMs propres ET les ROMs partagées avec son parent. Volumineux (duplication), mais chaque jeu fonctionne sans dépendre du parent (le BIOS reste séparé).

L'archive du parent contient les ROMs du parent et de tous ses clones. Très compact, mais incompatible avec certains émulateurs qui attendent une archive distincte par jeu.

Organisation des dossiers

Rangement des fichiers dans le dossier cible après consolidation. Spécifique aux DAT MAME.

⚠️ Incompatible avec le MAME standard

Le MAME d'origine attend les archives BIOS dans le même dossier que les ROMs. Si vous les déplacez dans bios/, les jeux qui en dépendent ne se lanceront pas, sauf si votre frontend gère un chemin BIOS séparé (convention Recalbox).

Les sets BIOS (isbios) sont rangés dans bios/ au lieu d'être à plat avec les jeux.

Convention MAME/Recalbox : un CHD de area51 va dans area51/area51.chd. Si désactivé, un CHD unique reste à plat (les jeux multi-CHD utilisent toujours un sous-dossier).

Pour un jeu sans aucune ROM classique (uniquement un CHD), crée un placeholder <jeu>.zip vide à côté du sous-dossier <jeu>/. Recalbox liste les jeux via les .zip présents. Implique le rangement du CHD en sous-dossier.

Compatibilité par système

Configurez les formats d'archives compatibles par système. Certains émulateurs ne supportent pas tous les formats. Les formats avec ⚠️ fonctionnent mais peuvent avoir des limitations.
