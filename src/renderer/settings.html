Compression des archives

Niveau de compression

Détermine le niveau de compression pour les archives ZIP/7Z

Ordre de priorité des formats

Les formats d'archives seront choisis dans cet ordre en fonction de la compatibilité avec le système du fichier DAT.

Options avancées

Si activé, les archives seront recompressées pour respecter le niveau sélectionné

⚠️ ATTENTION : Cette option ralentit FORTEMENT le processus !

L'application va tester TOUS les formats d'archives disponibles pour chaque jeu et ne garder que le format le plus compact.

  • Temps de traitement : x3 à x5 plus lent
  • Utilisation CPU : Maximale
  • Utilisation disque : Temporairement doublée

Recommandé uniquement si l'espace disque final est critique.

Teste tous les formats et garde le plus compact (très lent)

La compression solide améliore le taux de compression mais ralentit l'extraction

Utilise plusieurs cœurs du processeur pour accélérer la compression

Outils externes

7-Zip

Utilisé pour lire et créer les archives .7z et .rar

WinRAR

Alternative pour créer des archives .rar (optionnel)

UnRAR

Alternative pour extraire les archives .rar (optionnel, si 7-Zip n'est pas disponible)

chdman (MAME)

Version fournie avec l'application (recommandé)

Utilisé pour créer/extraire les images CD/DVD au format CHD (si version embarquée désactivée)

Ordre de priorité pour les archives RAR

Les outils seront utilisés dans cet ordre pour lire et extraire les archives RAR. Le premier outil disponible sera utilisé.

Compatibilité archives par système

Configurez les formats d'archives compatibles par système. Certains émulateurs ne supportent pas tous les formats. Les formats avec ⚠️ fonctionnent mais peuvent avoir des limitations.
